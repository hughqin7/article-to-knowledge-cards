# make-knowledge-cards

把一篇文章变成 3–5 张知识卡片 · Turn one article into 3–5 knowledge cards.

> 本仓库（`article-to-knowledge-cards`）发布的是 Agent Skill **`make-knowledge-cards`**，技能目录为 `skills/make-knowledge-cards/`。

## 介绍

`make-knowledge-cards` 是一个 Agent Skill。给它一篇文章——直接粘贴的正文，或本地的 `.md`/`.txt` 文件——它输出 3–5 张知识卡片（原文信息不足时会更少，并说明原因），每张卡片只讲一个知识点，包含四部分：

| 字段 | 说明 |
| --- | --- |
| 标题 | 知识点本身，例如「睡眠中的重放是记忆固化的必要环节」 |
| 核心知识 | 一句话把这个知识点说清楚 |
| 简明解释 | 2–4 句，说明它为什么成立、意味着什么 |
| 例子 / 自测 | 原文中的例子；原文没有例子时，改成一道自测问题 |

### 设计原则

- **只提取真正重要的知识。** 判断标准是「一个月后还用得上」；时刻表、票价、开通日期、客流预测这类只服务于当下的信息属于参考数据，不占卡片。
- **一张卡片只讲一个知识点。** 需要两句话才说得清的，其实就是两个知识点——拆开，或者丢掉一个。
- **重复内容自动合并。** 同一件事在文中被讲三遍，只出一张卡片。
- **不编造原文没有的信息。** 不新增事实、数字、人名，不做原文没有的推断；数字只照抄原文，不自行换算（例如不把 `85% vs 60%` 写成「相差 25 个百分点」）。
- **信息不足时不凑数量。** 原文只支撑 2 个知识点就只给 2 张，并说明第 3 个为什么没有。用户要的数量永远不构成多写一张弱卡片的理由。

## 使用方法

1. 把 `skills/make-knowledge-cards/` 整个目录放进你的技能目录（项目的 `skills/`，或 `~/.dsh/skills/`）。
2. 用自然语言触发即可：

   ```text
   帮我把这篇文章做成知识卡片
   <粘贴正文>

   把 notes.md 整理成知识卡片

   Turn this file into knowledge cards: report.md
   ```

卡片默认直接输出在对话里。需要保存成文件时说一句「存成 cards.md」即可。

## 输入输出示例

### 输入（节选）

```markdown
# 为什么睡不够会记不住东西

## 睡眠不是大脑的关机状态
……在非快速眼动睡眠的深睡阶段，大脑皮层会出现频率约 0.5 到 4 赫兹的高幅慢波，
这种慢波活动会以大约每秒一次的节奏在海马体和新皮层之间来回传递。……

## 重放是记忆固化的关键
……当大鼠进入慢波睡眠时，这些位置细胞会以与白天跑动时几乎相同的顺序重新放电，
只是速度加快了约 20 倍。如果在这一阶段干扰睡眠，大鼠第二天对路线的记忆明显变差。……

## 数字说明了什么
……睡眠充足组的平均回忆率为 85%，睡眠不足组为 60%。……

## 补觉回不来
……睡眠不足组在随后两天各睡 10 小时，回忆率只回升到 72%，仍低于睡眠充足组。……
```

### 输出

```markdown
原文：《为什么睡不够会记不住东西》｜共 5 张卡片

### 卡片 1：睡眠中的重放是记忆固化的必要环节
- **核心知识**：睡眠期间海马体会把白天的经历以慢波节律反复重放给新皮层，这种重放是记忆从临时存储转为长期存储的必要环节，而不是副产品。
- **简明解释**：深睡阶段的慢波频率约 0.5 到 4 赫兹，会以大约每秒一次的节奏在海马体和新皮层之间来回传递。海马体负责快速编码新经历但容量有限，新皮层容量大但学习速度慢，慢波期间的重放相当于把当天临时存放的内容一遍遍重放给新皮层；干扰这一阶段，记忆就会明显变差。
- **例子**：大鼠在迷宫中学习路线后，海马体的位置细胞在它进入慢波睡眠时会以与白天跑动时几乎相同的顺序重新放电，速度加快约 20 倍；若在这一阶段干扰睡眠，大鼠第二天对路线的记忆明显变差。

### 卡片 2：熬夜造成的记忆损失只能部分补回
- **核心知识**：睡眠不足造成的记忆损失，靠事后补觉只能部分挽回，不能完全补回。
- **简明解释**：在一项学生研究中，睡眠不足组即使在随后两天各睡 10 小时，回忆率仍低于睡眠充足组，说明延长睡眠只能部分抵消之前欠下的睡眠，而不是把损失清零。
- **例子**：睡眠不足组在随后两天各睡 10 小时后，回忆率只回升到 72%，仍低于睡眠充足组。

### 卡片 3：睡眠不足主要损害需要精确回忆的内容
- **核心知识**：睡眠不足对记忆的损害主要集中在需要精确回忆的题目上，对只需再认的题目影响很小。
- **简明解释**：同一项学生研究显示，两组的差距主要出现在需要精确回忆的题目上，判断题这类只需要再认的题目差距很小；也就是说，睡眠不足对不同记忆任务的影响并不一样，受影响更明显的是精确提取。
- **例子**：睡满 8 小时组的平均回忆率为 85%，只睡 4 小时组为 60%；差距主要出现在需要精确回忆的题目上，判断题这类只需再认的题目差距很小。
```

（此处截取前 3 张。完整输出还会包含「分散复习并保证当晚睡眠，胜过临考前通宵」和「午睡不能替代夜间慢波睡眠的记忆固化作用」两张卡片。注意卡片里的自测问题不带答案，数字也没有被换算成「相差 25 个百分点」。）

### 信息不足时的输出

对一篇只讲新地铁线路开通的短讯，Skill 不会硬凑 3–5 张，而是直接说明原因：

```markdown
来源：《本市地铁 7 号线今日开通运营》｜ 卡片数：0

原文是一则“地铁 7 号线今日开通”的消息，全文都属于参考信息，没有可支撑卡片的知识点：

- 参考信息（压缩为一行，不占卡片）：7 号线全长 23.6 公里、15 座车站（6 座换乘站），
  初期运营 6:00—22:30，高峰行车间隔 6 分 30 秒、平峰 9 分钟，起步价 3 元、
  全程最高 6 元，预计初期日均客流约 18 万人次，沿线新增公交接驳线路 4 条、调整 7 条。
- 文中唯一稍带主张的一句——市民王女士过去需在 3 号线换乘两次，现在可直达，
  单程节省约 20 分钟——讲的是“直达比换乘快”，读者没读这篇也能想到，
  不是这篇文章自己的知识。

原文只支撑 0 张卡片。要凑出 3-5 张，只能把参考数据和常识拆开包装，那只会得到
看起来像卡片、实际上学不到东西的填充。如果你有同一主题的深度材料，发给我即可做成 3-5 张卡片。
```

同样地，一份反复强调两三个结论的会议记录，会被合并成 1–2 张卡片，其余一次性范围决定压缩成一行参考信息，而不是拆成五张。

## 不支持

| 能力 | 现状 | 替代做法 |
| --- | --- | --- |
| 网页抓取 | 不支持 | 把正文复制粘贴过来 |
| PDF | 不支持 | 先另存为 `.md` / `.txt` |
| Anki 导出 | 不支持 | 直接复制卡片内容 |
| 图形界面 | 不支持 | 在对话里使用 |

## 验证

用官方 [skill-creator](https://github.com/openai/skills) 里的 `quick_validate.py` 校验（需要 `pyyaml`）：

```bash
python3 quick_validate.py skills/make-knowledge-cards
# Skill is valid!
```

脚本检查 YAML frontmatter 格式、必填字段与命名规则。本仓库当前已通过校验。本仓库不附带该脚本，请从官方仓库获取。
